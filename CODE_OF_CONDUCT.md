# Code Of Conduct

This project follows a simple contribution standard:

- Be respectful and specific.
- Discuss technical tradeoffs with evidence.
- Do not post private credentials, private datasets, or third-party data that
  cannot be redistributed.
- Keep issues focused on reproducible behavior, documentation gaps, or concrete
  feature proposals.

Maintainers may edit, hide, or remove content that is abusive, contains private
data, or creates legal/security risk for the project.
